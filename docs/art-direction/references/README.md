# Art direction references

Drop three reference images in this folder before closing Phase 0. These are the visual anchors we check every new asset against.

## Required

1. **`01_altos_odyssey.png`** — from *Alto's Odyssey*. A dusk-lit dune silhouette frame, ideally one that shows parallax depth. Source: Snowman's press kit (snowmanstudio.com) is the safest legally-cleared option.
2. **`02_monument_valley.png`** — from *Monument Valley* (Ustwo). A frame showing flat geometric shading and silhouette. Ustwo's press kit has screenshots licensed for editorial use.
3. **`03_third_choice.png`** — Pradeep's pick. Candidates discussed:
   - *Gris* (Nomada Studio) — watercolor minimalism, strong silhouette work
   - *Sky: Children of the Light* (thatgamecompany) — atmospheric color, robed characters
   - *Journey* (thatgamecompany) — the original silhouette-in-landscape template
   Commit with a one-line note on why it was picked.

## Rules for references

- Prefer press-kit or developer-provided screenshots to arbitrary web captures; press kits grant editorial/reference-use rights explicitly.
- PNG preferred, JPEG acceptable. Aim for ~1920×1080.
- These are reference material for our team, not training data for generative models and not assets we'd redistribute.
- If we ever need them for anything external (pitch deck, press), swap to assets whose license we've verified in writing.
